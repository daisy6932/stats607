# ADEMP — design template

Status: incomplete; finalize the topic and required instructor consultation before implementation.

## Aims
Specify the statistical question and hypotheses.

## Data-generating mechanisms
Specify distributions, equations, parameters, sample sizes, seeds, replication count, and all varying conditions.

## Estimands / targets
Define the true quantities and inferential targets.

## Methods
Specify estimators, tuning, confidence interval construction, and handling of failures.

## Performance measures
Define metrics and their Monte Carlo uncertainty; state how failures enter denominators.

## Design matrix
List every combination explicitly after choosing the design. Include a sanity-check condition and conditions favorable and unfavorable to the methods.

## Reproduction protocol
Document configuration, random number stream management, raw output schema, and commands when implemented.
